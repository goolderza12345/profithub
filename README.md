# ProfitHub

ระบบวิเคราะห์กำไรสำหรับผู้ขายออนไลน์ในประเทศไทย (MVP 1.0)

- **Next.js 16** (App Router) + TypeScript + Tailwind CSS 4
- ข้อมูลเก็บในเบราว์เซอร์ผ่าน **IndexedDB** (ไลบรารี `idb`) ไม่มีเซิร์ฟเวอร์หรือฐานข้อมูลภายนอก
- ข้อมูลจริงและ Demo อยู่คนละฐานข้อมูล (`profithub-real` / `profithub-demo`)
- ไลบรารี open source: `papaparse` (CSV), `recharts` (กราฟ), `lucide-react` (ไอคอน), `vitest` (ทดสอบ)

## ความปลอดภัยของข้อมูล (v1.1)

- **Backup/Restore:** ไฟล์ JSON มี checksum, ตรวจทุกรายการก่อนกู้คืน, ห้ามกู้คืนข้ามชุด (จริง ↔ Demo), เขียนใน transaction เดียว (ล้มเหลว = ข้อมูลเดิมอยู่ครบ)
- **จุดกู้คืนอัตโนมัติ:** เก็บสำเนาล่าสุด 5 จุดก่อนกู้คืน ลบชุดนำเข้า หรือลบข้อมูลทั้งหมด
- **Historical Cost Snapshot:** รายการขายบันทึกต้นทุนต่อชิ้น ณ วันนำเข้า การแก้ต้นทุนภายหลังไม่กระทบกำไรย้อนหลัง (ข้อมูลจาก v1.0 ถูกเติม snapshot ด้วยต้นทุนปัจจุบันตอนอัปเกรดฐานข้อมูล)
- **ตรวจข้อมูล:** จำกัดความยาว/ขนาดตัวเลข/จำนวนแถว, กันรายการซ้ำ 2 ชั้น (ตอนตรวจไฟล์ + unique index), ป้องกัน CSV formula injection ในไฟล์รายงาน

สูตรคำนวณทั้งหมดอยู่ใน `src/lib/profit.ts` (ดูคำอธิบายด้านบนไฟล์)

## คำสั่ง

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # unit tests (สูตรกำไร, CSV, รายงาน, Demo)
npm run lint
npm run build
```

## รูปแบบไฟล์ CSV ยอดขาย

```
order_id,order_date,channel,sku,quantity,unit_price,discount,refund,returned_qty,platform_fee,shipping_fee
```

คอลัมน์ 6 ตัวแรกบังคับ ที่เหลือว่างได้ (= 0) · วันที่รองรับ `YYYY-MM-DD` และ `DD/MM/YYYY` (พ.ศ. ได้) · รายการซ้ำตัดสินจาก ช่องทาง + เลขคำสั่งซื้อ + SKU
